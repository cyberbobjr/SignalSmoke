# Installation

## Requirements

- Project Zomboid **Build 42.21** or later (`versionMin=42.21`).
- No other mod is required.

## Steps

1. Subscribe to [Signal Smoke](https://steamcommunity.com/sharedfiles/filedetails/?id=3811010882) on the Steam Workshop.
2. In **Mods**, enable **Signal Smoke** (`batman_SignalSmoke`).
3. On a dedicated server, add `batman_SignalSmoke` to `Mods=` and `3811010882` to `WorkshopItems=`.

Some mods require Signal Smoke (for example Opération Artemis and Radio Survivor): you need to subscribe to it and enable it with them.

The mod can be added to an existing save: its items appear in containers that have not been looted yet.
