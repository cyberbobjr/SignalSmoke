# Installation

## Prérequis

- Project Zomboid **Build 42.21** ou plus récent (`versionMin=42.21`).
- Aucun autre mod n'est nécessaire.

## Étapes

1. S'abonner à [Signal Smoke](https://steamcommunity.com/sharedfiles/filedetails/?id=3811010882) sur le Steam Workshop.
2. Dans **Mods**, activer **Signal Smoke** (`batman_SignalSmoke`).
3. Sur un serveur dédié, ajouter `batman_SignalSmoke` à `Mods=` et `3811010882` à `WorkshopItems=`.

Certains mods exigent Signal Smoke (par exemple Opération Artemis et Radio Survivor) : il faut s'y abonner et l'activer avec eux.

Le mod peut être ajouté à une partie existante : ses objets apparaissent dans les conteneurs pas encore fouillés.
